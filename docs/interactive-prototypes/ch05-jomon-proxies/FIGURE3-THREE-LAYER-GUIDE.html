第二层：ggplot2（选做，可运行脚本）

在本地安装R和ggplot2；获取作者固定v3.0仓库（含R_images缓存）。执行：

git clone --branch v.3.0 --depth 1 https://github.com/ercrema/jomonPhasesAndPopulation.git /tmp/jomon-v3-audit
Rscript -e 'if (!requireNamespace("ggplot2",quietly=TRUE)) install.packages("ggplot2",repos="https://cloud.r-project.org")'
Rscript interactive-prototypes/ch05-jomon-proxies/figure3-ggplot2.R /tmp/jomon-v3-audit /tmp/jomon-figure3-output

运行命令中的脚本路径相对于教材仓库根目录；请先切换回教材根目录再执行。脚本加载作者缓存： - simdatesPithouses.RData：tblocks.trap（50个100年区间×模拟次数），tbs2（51个边界）；panel a均值、2.5%和97.5%分位数。 - spdRes.RData：spdDataSPD_blocks$sumblock；panel b作者已经计算的SPD。 - comp.RData：tblockRoll10.trap；panel c滚动相关均值、2.5%和97.5%分位数（忽略NA）。

脚本用相邻时间边界中点作为100年箱的ggplot x位置（例如7950、7850…3050 cal BP），x轴由老到新逆向显示；输出三个CSV、三个PNG和三面板PDF。脚本会在缓存对象缺失、区间长度不符或100年箱宽不符时停止，不能自行补造结果。

重要： panel a/c阴影或误差线是模拟结果的经验分位数，不可未经论证称为独立样本的频率学置信区间；panel b是作者的校正SPD，不是未经校正的CRA直方图。ggplot2重绘是作者缓存结果的可视化复算，不是OxCal后验的重新估计。新版ggplot的图形外观不必逐像素等同原Base R图，但数值与轴单位必须相符。

第三层：研究级复现（进阶）

作者README与log.R给出研究级工作流： 1. 从data/c14dates.csv（2132行）读取测年记录；对CombineGroup运行outlierExcluder筛选；缓存c14data.RData保留2120行，12条差额已逐条比对。 2. 用OxCal v4.4及IntCal20/Marine20进行阶段建模，生成多种阶段内分布假设的OxCal脚本；比较agreement并进行第二轮处理。原作者README说明这一阶段耗时较长（log.R中提及约70–90小时），不作为本科必做。 3. 从data/suzuki五县CSV汇总233行Counts=9612，再通过orgTable展开为住宅记录；按阶段归属、阶段边界及阶段内不确定性进行5000次模拟。 4. 使用rcarbon构建SPD及5000次随机日历日期抽样，按100年区间汇总，计算两种代理的相关与1000年滚动相关；输出RData。 5. 运行manuscript/figures/figurelog.R复现作者Base R原图，再用本课程ggplot2脚本绘制同一缓存的教学版本。

研究级复现需要锁定R及依赖版本、OxCal执行方式、校正曲线、随机种子/随机抽样条件与输出hash。不能把作者缓存加载成功称为完整分析重跑，也不能保证跨版本随机模拟逐点一致。数据与版权核查完成前，不将全部作者原始文件复制到教材公开仓库。
