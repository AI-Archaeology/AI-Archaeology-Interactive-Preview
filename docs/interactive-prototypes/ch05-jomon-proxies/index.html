为什么不能说“12条测年都不可靠”？

作者的代码使用组合测年的统计检验和一致性指标筛选记录。我们已经核对筛选前后的12个LabCode，但没有重新运行OxCal或复核每个排除判断的全部统计依据。

为什么不能直接把9612当作精确年代的人口数据？

住宅计数经过作者按陶器阶段归属和年代不确定性建模，才用于推断人口代理。住宅也不等于居民人数；保存、调查与阶段归属都会影响可见数量。
